<Card title="성공 기준(SC)">
[웹 페이지 세트](../../../glossary/set-of-web-pages) 안의 여러 [웹 페이지](../../../glossary/web-page)에서 반복되는 내비게이션 메커니즘은, 사용자가 변경하지 않는 한 반복될 때마다 [동일한 상대적 순서](../../../glossary/same-relative-order)로 나타나야 한다.
</Card>

### 의도

이 성공 기준의 목적은 웹 페이지 세트 안에서 반복되는 콘텐츠와 상호작용하며 특정 정보나 기능을 여러 번 찾아야 하는 사용자를 위해, 일관된 시각적 레이아웃과 소스 순서를 사용하도록 장려하는 것이다.

화면 확대를 사용하여 화면의 작은 부분만 한 번에 표시하는 저시력 사용자는 반복되는 콘텐츠를 빠르게 찾기 위해 시각적 단서와 페이지 경계를 자주 활용한다.
반복되는 콘텐츠를 동일한 순서로 제시하는 것은 공간 기억이나 디자인 안의 시각적 단서를 이용해 반복 콘텐츠를 찾는, 화면을 보고 이용하는 사용자에게도 중요하다.

마찬가지로, 앞을 보지 못해 페이지의 콘텐츠를 순차적으로 탐색하는 사용자는 내비게이션 메커니즘이 페이지의 전체 소스 순서와 구조에 대해 일관된 순서로 나타날 때 도움을 받는다.

이 절에서 "동일한 순서"라는 표현을 사용했다고 해서 하위 내비게이션 메뉴를 사용할 수 없다거나, 보조 내비게이션 블록이나 페이지 구조를 사용할 수 없다는 뜻은 아니라는 점에 유의해야 한다.
오히려 이 성공 기준은 웹 페이지 전반에서 반복되는 콘텐츠와 상호작용하는 사용자가 자신이 찾는 콘텐츠의 위치를 예측하고, 그것을 다시 만났을 때 더 빠르게 찾을 수 있도록 돕기 위한 것이다.

사용자는 적응형 사용자 에이전트를 사용하거나 환경 설정을 조정하여, 정보가 자신에게 가장 유용한 방식으로 표시되도록 순서를 바꿀 수 있다.

### 이점

* 반복되는 구성 요소가 사이트의 각 페이지에서 동일한 순서로 나타나도록 하면, 사용자는 각 페이지에서 원하는 것을 어디서 찾을 수 있는지 예측할 수 있다는 확신을 갖게 된다. 이는 인지적 제약이 있는 사용자, 저시력 사용자, 지적 장애가 있는 사용자, 그리고 시각장애 사용자에게 도움이 된다.

### 예제

<dl>
    <dt>일관되게 배치된 컨트롤</dt>
    <dd>사이트의 모든 웹 페이지에서 검색 필드가 마지막 항목에 있다. 사용자는 검색 기능을 빠르게 찾을 수 있다.</dd>
    <dt>확장되는 내비게이션 메뉴</dt>
    <dd>내비게이션 메뉴에 사이트의 주요 섹션으로 연결되는 링크 일곱 개가 목록으로 담겨 있다. 사용자가 이 항목 중 하나를 선택하면, 하위 내비게이션 항목 목록이 최상위 내비게이션 메뉴에 삽입된다.</dd>
    <dt>일관되게 배치된 내비게이션 건너뛰기 컨트롤</dt>
    <dd>웹사이트의 모든 페이지에 "내비게이션 건너뛰기"(또는 "본문 바로 가기") 링크가 첫 번째 링크로 포함되어 있다. 이 링크를 통해 사용자는 제목 정보와 내비게이션 콘텐츠를 빠르게 건너뛰고 페이지의 본문과 상호작용을 시작할 수 있다.</dd>
    <dt>내비게이션 바로 가기 링크</dt>
    <dd>웹 페이지 세트에서 내비게이션 콘텐츠가 각 페이지의 끝에 일관되게 배치되어 있다. "내비게이션 바로 가기" 링크는 각 페이지의 시작 부분에 일관되게 배치되어 있어, 키보드 사용자가 필요할 때 쉽게 찾을 수 있다.</dd>
</dl>

### 기법

이 섹션의 각 번호가 매겨진 항목은 접근성 지침 실무 그룹이 이 성공 기준을 충족하기에 충분하다고 판단하는 기법 또는 기법의 조합을 나타낸다. 기법은 기준의 최소 요구 사항을 넘어설 수 있다. 이러한 기법에서 포괄하지 않은 기준 충족의 다른 방법이 있을 수 있다. 다른 기법 사용에 대한 정보는 [WCAG 성공 기준에 대한 기법 이해](../understanding-techniques), 특히 "기타 기법" 섹션을 참조하라.

#### 충분 기법
